# 🎥 Guide de démarrage de live - Streamyz

## 🚨 Problème : Le bouton "Start" ne fonctionne pas

### **Solutions étape par étape :**

#### **1. Vérifier la connectivité réseau**
- ✅ **Indicateur vert** : "Connecté et prêt à démarrer"
- ❌ **Indicateur rouge** : "Pas de connexion réseau"

**Si l'indicateur est rouge :**
1. Vérifiez votre connexion WiFi ou données mobiles
2. Redémarrez l'application
3. Attendez quelques secondes pour la reconnexion automatique

#### **2. Vérifier les permissions**
L'application demande automatiquement :
- 🎤 **Microphone** : Pour l'audio du live
- 📷 **Caméra** : Pour la vidéo du live
- 💾 **Stockage** : Pour sauvegarder les enregistrements

**Si les permissions sont refusées :**
1. Allez dans **Paramètres** > **Applications** > **Streamyz**
2. Activez **Microphone** et **Caméra**
3. Redémarrez l'application

#### **3. Vérifier la description**
- Le champ "Description du live" ne doit pas être vide
- Maximum 100 caractères autorisés
- Exemple : "Mon premier live sur Streamyz !"

#### **4. Vérifier l'état de l'utilisateur**
- Vous devez être connecté à votre compte
- Si non connecté, l'application affiche un message d'erreur

### **Messages d'erreur et solutions :**

#### **"Pas de connexion réseau"**
```
Solution : Vérifiez votre connexion Internet
- WiFi : Vérifiez que vous êtes connecté
- Données mobiles : Activez les données mobiles
- Redémarrez l'application
```

#### **"Permissions requises non accordées"**
```
Solution : Accordez les permissions
- Paramètres > Applications > Streamyz
- Microphone : ✅ Activé
- Caméra : ✅ Activé
```

#### **"Utilisateur non connecté"**
```
Solution : Connectez-vous à votre compte
- Retournez à l'écran de connexion
- Entrez vos identifiants
- Réessayez de démarrer le live
```

#### **"Veuillez ajouter une description"**
```
Solution : Ajoutez un titre à votre live
- Exemple : "Live gaming ce soir"
- Exemple : "Discussion avec les abonnés"
- Exemple : "Tutoriel de cuisine"
```

### **Démarrage réussi :**

#### **✅ Indicateurs de succès :**
1. **Indicateur vert** : "Connecté et prêt à démarrer"
2. **Bouton actif** : "DÉMARRER LE LIVE" en violet
3. **Description remplie** : Champ non vide
4. **Permissions accordées** : Pas de message d'erreur

#### **🔄 Processus de démarrage :**
1. Cliquez sur "DÉMARRER LE LIVE"
2. Le bouton affiche "Chargement..."
3. L'application crée le live dans la base de données
4. Navigation automatique vers l'écran de live
5. Démarrage de la diffusion

### **En cas de problème persistant :**

#### **Redémarrage complet :**
1. Fermez complètement l'application
2. Redémarrez votre appareil
3. Relancez l'application
4. Réessayez de démarrer le live

#### **Vérification des services :**
1. **Firebase** : Vérifiez votre connexion Internet
2. **ZegoCloud** : Service de streaming automatique
3. **Permissions** : Vérifiez dans les paramètres

#### **Support technique :**
Si le problème persiste :
1. Notez les messages d'erreur exacts
2. Vérifiez votre version d'Android/iOS
3. Contactez le support avec ces informations

### **Conseils pour un démarrage optimal :**

#### **Avant de démarrer :**
- ✅ Connexion Internet stable
- ✅ Permissions accordées
- ✅ Description préparée
- ✅ Environnement calme
- ✅ Batterie suffisante

#### **Pendant le démarrage :**
- ⏳ Patientez pendant le chargement
- 📱 Ne fermez pas l'application
- 🔄 Évitez de changer d'application

#### **Après le démarrage :**
- 🎥 Vérifiez que la caméra fonctionne
- 🎤 Testez le microphone
- 👥 Invitez vos abonnés
- 💬 Interagissez avec le chat
